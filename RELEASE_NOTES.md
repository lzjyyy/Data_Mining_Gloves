# LHand-PC v1.0.0

This release provides the packaged Windows desktop application for the `LhandPC` branch.

## Assets

- `LHand-PC.exe`: Windows executable. Run directly after download.
- `LHand-PC.zip`: Compressed release package for easier distribution.

## Features

- PC-side control software for the low-degree-of-freedom left hand.
- Serial port configuration and data communication.
- Integrated URDF-based 3D hand model viewer.
- Includes required `youshou_urdf` model resources and application assets.

## Usage

Download `LHand-PC.zip` and extract it, or download `LHand-PC.exe` directly.

If Windows shows a security prompt, choose "More info" and continue running the application.
